# GuideHint

Short, skippable guidance. Direct, never chatty.

- **Tour tip**: a `night` card with an arrow, "Tip 2 of 3", a bold heading and one sentence; marigold "Next" and a "Skip". Three tips at most, shown once.
- **Beacon**: a pulsing marigold dot by a feature not yet used.
- **Help panel**: `marigold-soft`, info icon, one question, one link.
- **Toast**: `night`, marigold check, past tense, 4 seconds.
