# Badge

Short facts and trust marks.

- **Verified kennel stamp**: a rotated mono stamp in `verified`, set on the photo of every dog from an inspected kennel. It is the most recognisable trust mark on the site.
- **Verified seller** badge with a shield icon on seller cards.
- **Level** badges for working titles (IGP 1–3, PSA). Protection level itself uses the ProtectionScale, not a badge.
- **Status dots** in the K9 file tab: marigold = Available, ash = Reserved.
