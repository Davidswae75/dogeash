# DogCard (K9 file)

Each listing is a K9 file: the record a working-dog handler would keep, so buyers get the facts first.

- **File tab** on `night`: file number (`DG-0412`) and status dot.
- **Photo** 4:3 with the verified kennel stamp.
- **Name** in expanded `display`, then breed · sex · city.
- **ProtectionScale**: level and five bars. This is the first thing buyers compare.
- **Facts row**: age, weight, hip grade, in `spec` mono, divided by hairlines.
- **Price** and "View file →".
- Grid: 3 columns from 1024px, 2 from 640px, 1 below.
