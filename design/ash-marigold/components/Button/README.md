# Button

Buttons are firm and direct: 48px tall, bold label, verb first.

- **Primary** (`action` / `on-action`): the main action on a page. One per view.
- **Marigold** (`marigold` / `on-marigold`): the single starting action on Home and the match flow ("Find my guard dog"). Not on listing pages.
- **Outline**: 2px `ink` border for secondary actions ("Book a visit").
- **Ghost**: `action` text with an arrow for "View K9 file →" style links.
- On `night` blocks use the `on-night` outline variant.
